# Ambient Expense Agent

This repository contains the Ambient Expense Agent built using the Google Agent Development Kit (ADK).

## Project Structure

```text
ambient-expense-agent/
├── ambient_expense_agent/    # Initial agent directory
│   ├── __init__.py
│   ├── agent.py              # Main agent definition
│   └── .env                  # Environment configuration
├── pyproject.toml            # Project configuration and dependencies
└── README.md                 # Project documentation
```

## Getting Started

1. Set up your environment variables in `ambient_expense_agent/.env`.
2. Install the dependencies using `pip` or `uv`.
